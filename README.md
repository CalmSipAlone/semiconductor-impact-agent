# 半导体产业链影响分析智能体

基于大语言模型的金融投研竞赛项目方案。研究外部事件沿半导体产业链的传导路径，以及对相关企业经营和盈利的影响。

## 当前状态

本仓库目前保存项目计划及讨论文档，尚未实现可运行系统。资料整理日期：2026-10-08。

- 原计划书主线：以美国出口管制政策升级为触发事件，分析设备材料、设计制造封测及下游应用的影响。
- 新增讨论：考虑光刻胶及其树脂等上游原料的价格变化。
- 原材料价格案例是否成为主线、材料层级、企业名单和计算方法，尚待团队确认。
- 原计划书中的政策、行业统计、参考文献及比赛日期尚需核验，不应视为本仓库已经证实的事实。

## 首版范围建议（尚未确认）

以一条材料链、3～5家相关企业和一个事件案例，完成：

> 证据查询 → 关系查询 → 参数获取 → 数值计算 → 结构化报告 → 执行追溯

该建议需要团队讨论通过后才能作为实施范围，不代表原计划书已经作出这些限定。

## 协作与数据

提交资料时记录来源、日期、页码、单位、规格与核验状态。真实数据、估算参数和情景假设分别标注。原始第三方文档的再分发权限需单独核实；本仓库仅收录项目方案文字和空白模板。

API密钥、个人账号信息、模型调用日志中的敏感信息及未核实再分发权限的数据，不应提交到公开仓库。

公开可见性不等于授予开源许可证；许可证由团队后续决定。
