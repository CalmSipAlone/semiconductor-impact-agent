# 计划书模糊与冲突审查

## 审查范围

依据用户提供的项目计划书与比赛要求截图，检查文字一致性和实施细节。本文没有完成对政策、行业统计和赛事日期的外部事实核验。

## 五项重点

| 内容 | 原文情况 | 判断 |
| --- | --- | --- |
| 核心研究问题 | 多处明确以美国出口管制政策升级为触发事件 | 主线清楚，没有直接冲突；新增价格分析需要说明与政策主线的关系 |
| 材料链深度 | 列光刻胶、特种气体、CMP等，没有展开具体原料 | 分析粒度模糊；没有明确承诺追溯树脂及更上游原料 |
| 企业范围 | 写上下游上市公司和各环节企业，没有名单或筛选标准 | 覆盖范围模糊 |
| 量化目标 | 提出量化企业经营和盈利影响 | 缺指标、公式、参数来源和缺失数据处理 |
| 传导机制 | 提出量化传导速度和强度 | 研究问题清楚，实现方法未展开 |

## 明确的时间冲突

阶段四写“2026年11月”提交初赛材料，时间节点表写“9月10日—10月18日”报名与作品提交。两处应依据正式通知统一。

## 需要补充的边界

1. C构建知识图谱、B负责数据库、D负责分析引擎，尚未明确内容整理与程序实现的边界。
2. A负责报告撰写与润色，D负责自动报告生成，需要说明生成、人工审核和展示的交接。
3. 封闭/半封闭环境与网络搜索、抓取、模型API调用并非必然冲突，但允许访问的服务和离线处理方案未说明。
4. “全流程自动化”与人工审核可以并存，但需标出哪些步骤自动、哪些需要人工准备或核验。
5. 原文允许模拟数据补充真实数据，但没有规定真实、估算与模拟的标注及适用范围。
6. 模型和框架提供多个候选，向量数据库、图数据库、多Agent、MCP等实现承诺需与首版能力及比赛要求统一。
7. “可复现”需要具体定义：数据与计算可复现、操作可追溯、模型响应可回放，与模型重跑逐字一致是不同要求。

## 资料核验事项

- 核验MATCH等政策名称、状态、适用范围及原文依据。
- 核验国产化率、市场份额、资金投向等数字及时间口径。
- 补充每个核心背景事实的直接来源。
- 解释或移除与半导体项目关联未说明的“电力体制改革意见”等参考文献。
- 核验赛事要求、提交日期、现场环境和模型接入规定。

这些事项不意味着背景说法已被证伪，也不意味着已经证实；应完成核验后再用于正式分析。
