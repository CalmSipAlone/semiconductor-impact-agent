# 团队范围讨论清单

## 讨论目的

细化原计划书实施范围。以下收缩方案为此前讨论建议，未得到团队确认，不替代原文的政策分析主线。

| 议题 | 需要决定 | 首版建议 |
| --- | --- | --- |
| 1. 核心问题 | 政策冲击或原料涨价哪个为主？价格是独立案例还是政策传导的一部分？ | 一个具体主事件和一个核心问题 |
| 2. 材料链 | 哪类光刻胶、哪些树脂/溶剂？是否追溯到更上游？ | 一类光刻胶、2～3种主要原料，先向上追溯一层 |
| 3. 企业范围 | 具体企业名单、入选依据、关系是否有证据？ | 3～5家资料较充分的相关企业 |
| 6. 量化目标 | 成本、毛利还是净利润？公式、参数及缺失处理？ | 先算成本敏感性，参数充分时分析毛利 |
| 7. 传导机制 | 转嫁比例、传导时间、库存、合同及替代能力如何处理？ | 少量关键参数和低/中/高情景 |

化学追溯是否继续扩展，依据影响重要性、证据可获得性及路径是否可验证决定。光刻胶属于制造过程中的工艺材料，关系设计应避免将其简单表述为最终芯片保留的组成部分。

## 范围确认句

> 我们以【具体事件】为起点，研究【具体原料→具体光刻胶→下游制造环节】，覆盖【企业名单】，计算【成本或毛利指标】，并在【价格转嫁、传导时间等假设】下比较不同情景。

## 会议需要留下的决定

- [ ] 主事件、核心问题与输入输出
- [ ] 材料类别、规格和追溯深度
- [ ] 企业名单及关系证据要求
- [ ] 数据来源、时间区间和资料负责人
- [ ] 指标、公式、参数来源和缺失处理
- [ ] 必须完成的功能及后续功能
- [ ] 验收案例和专业审核人
- [ ] 每人的具体交付物和交付日期
- [ ] 模型接入、现场网络与运行条件
- [ ] 统一计划书日期并核验参考资料

## 首版完整流程建议

本地资料导入 → 证据查询 → 关系查询 → 参数获取 → 数值计算 → 结构化报告 → 运行追溯。

全面实时爬取、所有材料链、复杂估值、股价预测和复杂多智能体协作是否实现，由团队在基本流程验收后决定。
